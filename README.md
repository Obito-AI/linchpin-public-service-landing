# 린치핀아카데미 공무원 유입 랜딩페이지

린치핀아카데미의 핵심인 `선배 공무원의 Zoom LIVE → 녹화영상 복습 → 업무 적용` 흐름을 보여주는 독립 랜딩페이지입니다. 같은 내용을 일반형과 브루탈리즘형, 두 가지 디자인으로 만들었습니다.

- [일반 프리미엄 버전](https://obito-ai.github.io/linchpin-public-service-landing/)
- [브루탈리즘 버전](https://obito-ai.github.io/linchpin-public-service-landing/brutalist/)
- [린치핀아카데미 공식 홈페이지](https://linchpin-academy.kr)

## 반영한 실제 기능

- 월 2회 Zoom 공개강의와 LIVE 신청·조회
- 지난 강의 영상, 태그 탐색, 진도·수강 완료 확인
- 강의에서 배운 것을 업무에 써 보는 성장노트
- 업무서식, 노션 템플릿, AI 도구, 커뮤니티
- 만든 프로그램을 영상·배포 링크·GitHub·HTML과 함께 등록하고 승인 뒤 공개하는 기능
- 출석·수강·LIVE 참여·후기로 쌓는 핀
- 린치핀아카데미가 시작된 배경을 담은 Vimeo 브랜드 영상

기능과 운영 방식은 공식 홈페이지 및 Obsidian에 정리된 사용설명서·FAQ·사업구상·성장노트 자료를 대조해 확인했습니다.

## 디자인 기준

- Dropbox의 공식 린치핀아카데미 로고 원본을 사용
- 간다 마사노리의 PASONA 흐름을 쓰되, 억지 마감이나 과장된 약속은 넣지 않음
- 일반 버전은 코발트·코랄·민트 계열과 Zoom 강의 장면을 사용
- 브루탈리즘 버전은 검정·형광 노랑·오렌지·시안과 강한 타이포그래피를 사용
- 공식 홈페이지 문장을 옮기지 않고, 실제 운영 내용을 바탕으로 새로 집필
- 가짜 후기·전환율·마감 압박은 사용하지 않음
- 모바일·키보드 탐색·모션 축소 환경 지원

## 로컬 실행

```bash
python3 -m http.server 4173
```

일반 버전은 `http://localhost:4173`, 브루탈리즘 버전은 `http://localhost:4173/brutalist/`을 엽니다.
